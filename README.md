# Tascons - Premium Streaming Shop SPA

Una **Single Page Application (SPA)** completa, modular y 100% funcional para una tienda premium de pantallas de streaming y servicios digitales.

## 🎨 Características

✅ **Sistema de Diseño Café Premium** - Paleta monocromática sofisticada  
✅ **Arquitectura Modular** - Componentes reutilizables y escalables  
✅ **Responsive Design** - Funciona perfectamente en todos los dispositivos  
✅ **Animaciones Fluidas** - Microinteracciones elegantes  
✅ **Accesibilidad WCAA AA+** - Cumple estándares internacionales  
✅ **Optimizado para SEO** - Metadatos y Schema.org  
✅ **Performance** - Build optimizado con Vite  

## 🚀 Inicio Rápido

### Instalación
```bash
git clone https://github.com/Tascons/org.git
cd org
npm install
```

### Desarrollo
```bash
npm run dev
```
Accede a `http://localhost:3000`

### Build Producción
```bash
npm run build
```

### Preview
```bash
npm run preview
```

## 🎨 Sistema de Diseño

El proyecto utiliza una **paleta monocromática de cafés** con:

- **12 tonos de café** organizados en 4 categorías
- **Espaciado breathe-room** para máxima elegancia
- **Border radius suavizado** para modernidad
- **Transiciones fluidas** para microinteracciones
- **Sombras sofisticadas** para jerarquía visual

Ver [DESIGN_SYSTEM.md](./DESIGN_SYSTEM.md) para documentación completa.
